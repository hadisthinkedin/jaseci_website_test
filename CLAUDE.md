# CLAUDE.md

## Project
Redesign of **jaseci.org**. Frontend only. Stack: **Next.js (App Router) + Tailwind CSS**, deployed on Vercel.

See `PLAN.md` for the current task list.

## Design rules — read before any UI work

1. **Design rulebook:** `.claude/ui-design-rulebook.md` — how to use the design system.
2. **Design system (source of truth):** `design-system.md` — locked tokens for colors, typography, spacing, etc.

Before producing or changing any UI, read both. Use only tokens defined in `design-system.md`. Never invent colors, fonts, or visual effects the system excludes.
